description: Switch vision mode to auto (proactive image recognition)
---
Switch this session's vision mode to **AUTO (自动)**: from now on, whenever an image is
relevant to the current task, call the vision tool yourself — `vision_describe` /
`vision_batch` if MCP is set up, otherwise `python vision.py <image>` — and analyze the
result, without waiting to be asked each time. Batch when possible, and only call it
when an image is genuinely relevant.
